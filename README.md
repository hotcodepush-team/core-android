# core-android, the Maven repository

This branch is the Maven repository of `com.hotcodepush:core-android` until the library is on Maven Central: CI publishes every commit on `main` here, versioned by the commit's full sha. A consumer adds `https://raw.githubusercontent.com/hotcodepush-team/core-android/maven/` to its repositories and pins `com.hotcodepush:core-android:<full sha>`.
